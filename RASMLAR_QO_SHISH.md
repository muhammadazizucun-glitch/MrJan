# MRJAN saytiga rasmlar qo'shish

1. `server/static/images/` papkasini yarating.
2. Logo, korxona rasmi yoki boshqa rasmlarni shu yerga tashlang.
3. Flask HTML shablonida:
   `<img src="/static/images/logo.png" alt="MRJAN">`
4. APK serverdagi saytni ochgani uchun rasmlar ham APK ichida emas, Flask serverdan ko'rinadi.

Muhim: siz yuborgan main.py'da rasm yuklash funksiyasi hozircha yo'q.
